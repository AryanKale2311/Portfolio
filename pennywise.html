PERSONAL FINANCE · INDEPENDENT PROJECT

PennyWise.

A personal finance and expense-management project built across two platforms: a responsive web experience and a native Android application. The goal is to make everyday budgeting easier to understand, organize, and maintain.

01 / PROJECT OVERVIEW

Turning everyday spending into clearer decisions.

PennyWise is being developed as a practical tool for recording expenses, understanding spending patterns, and working within a monthly budget. Building both a website and an Android app has helped explore how the same product idea can be implemented across different platforms.

01 — THE WEB EXPERIENCE

A browser-based finance dashboard

The web version uses HTML, CSS, and JavaScript. It includes a dashboard, transaction management, category-based analytics, budgets, multi-currency entries, CSV export, and browser-based persistence using localStorage. The website is published through GitHub Pages.

02 — THE ANDROID APP

A native mobile application

The Android version is being built in Android Studio using Kotlin and Jetpack Compose. It uses Room for local data storage and starts with a personalized onboarding flow so each installation can be set up with the user's own details and budget.

02 / CORE CAPABILITIES

Designed around a user's budget cycle.

The project has moved beyond a static interface into working application flows and local data handling. Current functionality and implementation differ slightly between the web and Android versions.

FEATURE 01

Personalized onboarding

New users enter their own profile information and monthly budget before reaching the dashboard.

FEATURE 02

Expense organization

Record and organize transactions to build a clearer picture of day-to-day spending.

FEATURE 03

Custom budget cycle

Choose a monthly reset day from 1 to 31, rather than being restricted to a calendar-month start.

FEATURE 04

Automatic and manual rollover

The app checks for a new cycle when opened, and also provides a manual reset option.

FEATURE 05

Financial history

Previous cycle transactions can be archived so a new cycle can begin without losing the older records.

FEATURE 06

Unused budget preference

Choose whether unused budget should carry forward or the next cycle should begin with the original budget amount.

03 / TECHNOLOGY & LEARNING

Learning by building across platforms.

Developing PennyWise has involved working through the complete development workflow: designing interfaces, structuring app screens, configuring Android dependencies, handling local persistence, troubleshooting Gradle builds, and publishing a static website through GitHub Pages.
