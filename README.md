# Aryan Kale — Portfolio Website

A responsive, dark futuristic personal portfolio built with plain HTML, CSS, and JavaScript. Designed for GitHub Pages; no build tools or dependencies required.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, theme, illustrations, animations
- `script.js` — mobile navigation, scroll progress, reveal animations
- `assets/` — optional images or downloadable resume

## Publish on GitHub Pages
1. Open the `Portfolio` repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder if needed.
4. Commit to the `main` branch.
5. Confirm **Settings → Pages** is set to deploy from `main` and `/(root)`.
6. Wait for the `pages build and deployment` workflow to finish, then open **Visit site**.

## Personalize before sharing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your public contact email.
- Replace the LinkedIn link with your real profile URL, or remove it if you do not have one.
- Add a PDF resume to `assets/` and add a link if you want a downloadable CV.
- Review the project descriptions and academic details for accuracy before publishing.

## Notes
- This site uses Google Fonts from a CDN; if fonts are blocked, system fonts will be used.
- All project visuals are CSS illustrations, not screenshots of deployed products.
- Keep private information such as phone number or home address off a public website unless you intentionally want to publish it.
