# Aryan Kale Portfolio — Cream & White Edition

Responsive portfolio built with HTML, CSS, and JavaScript. No build tools or paid hosting required.

## Files
- `index.html` — all content and sections
- `style.css` — cream/white visual design and responsive layout
- `script.js` — mobile navigation and reveal animations
- `assets/profile.jpg` — add your own portrait here

## Add your photo
1. Choose a clear portrait photo.
2. Rename it exactly `profile.jpg`.
3. Upload it inside the `assets` folder in your GitHub repository.
4. The page shows a designed AK placeholder until the image exists.

## Upload to GitHub Pages
1. Download and extract this ZIP.
2. Open your existing Portfolio repository.
3. Choose **Add file → Upload files** and upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. Commit to `main`. Replace the existing `index.html` when prompted.
5. Check **Actions** for a green `pages build and deployment` check.
6. Refresh `https://AryanKale2311.github.io/Portfolio/`
